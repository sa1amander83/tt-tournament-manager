# Инструкция по установке и запуску

*[Read this in English](SETUP.en.md)*

## Требования

- Аккаунт Google (для Google Таблиц, Форм, Диска и Apps Script).
- Для разработки/тестирования кода на компьютере: Node.js 18 или новее (только чтобы гонять автотесты `tests/`, для самого приложения не нужен).
- (Опционально) [`clasp`](https://github.com/google/clasp) — CLI Google для синхронизации локальных файлов с проектом Apps Script. Без него можно копировать файлы вручную через веб-редактор.

## Вариант 1: без clasp, через веб-редактор Apps Script

1. Создайте новую Google Таблицу (sheets.new).
2. В таблице откройте меню **Расширения → Apps Script**. Откроется редактор кода, привязанный к этой таблице.
3. В редакторе удалите заготовку `Code.gs`, которая создаётся по умолчанию.
4. Для каждого файла `*.gs` из этого репозитория (`categories.gs`, `config.gs`, `draw.gs`, `drive.gs`, `forms.gs`, `logging.gs`, `matches.gs`, `menu.gs`, `participants.gs`, `reports.gs`, `setup.gs`, `teams.gs`, `testing.gs`, `theme.gs`, `wizard.gs`) — создайте в редакторе новый файл с тем же именем (кнопка «+» → «Скрипт») и вставьте в него содержимое соответствующего файла.
5. Сохраните проект (Ctrl+S / значок дискеты).
6. Перезагрузите вкладку с таблицей в браузере — при открытии сработает `onOpen()` из `menu.gs`, и появится меню **🏓 TT Tournament Manager**.
7. Первый запуск попросит выдать скрипту разрешения (доступ к таблице, Google Диску, Google Формам от вашего имени) — это стандартный OAuth-запрос Google для скриптов, привязанных к вашему аккаунту.

## Вариант 2: через clasp (рекомендуется для разработки)

1. Установите clasp глобально:
   ```bash
   npm install -g @google/clasp
   ```
2. Авторизуйтесь:
   ```bash
   clasp login
   ```
3. Включите Apps Script API для своего аккаунта (один раз): https://script.google.com/home/usersettings
4. Создайте новый проект Apps Script, привязанный к новой Google Таблице:
   ```bash
   clasp create --type sheets --title "TT Tournament Manager" --rootDir ./tournament
   ```
   Эта команда создаст файл `.clasp.json` в каталоге `tournament/` — он **намеренно не хранится в git** (см. `.gitignore`), так как содержит идентификатор конкретного личного проекта Apps Script.
5. Загрузите код в проект:
   ```bash
   cd tournament
   clasp push
   ```
6. Откройте таблицу командой:
   ```bash
   clasp open --webapp
   ```
   либо через ссылку, которую вывела команда `clasp create`.
7. Перезагрузите таблицу в браузере, чтобы появилось меню **🏓 TT Tournament Manager**.

## Первый запуск турнира

1. В таблице откройте меню **🏓 TT Tournament Manager → Новый турнир** (или аналогичный пункт мастера — см. `wizard.gs`/`menu.gs`).
2. Пройдите мастер: укажите название турнира, формат, количество кортов, включите/выключите режим «смешанный турнир».
3. Мастер (`setup.gs`) автоматически:
   - создаст нужные листы с заголовками;
   - применит оформление (`theme.gs`);
   - создаст папку турнира на Google Диске и перенесёт туда таблицу (`drive.gs`);
   - создаст Google Форму регистрации участников (`forms.gs`);
   - сохранит итоговые настройки (`config.gs`).
4. Поделитесь ссылкой на форму регистрации с участниками.
5. После сбора заявок запустите распределение по категориям (`categories.gs`) и жеребьёвку (`draw.gs`) из меню.
6. Ведите результаты матчей через лист «Матчи» и функции `matches.gs`; итоговые отчёты — через `reports.gs`.

## Автотесты

В проекте есть автотесты для «чистой» логики (не зависящей от `SpreadsheetApp`), в первую очередь для `categories.gs`. Запускаются локально, без Google-аккаунта:

```bash
cd tournament
node --test tests/
```

Файл `tests/gas-loader.js` подгружает нужные `.gs`-файлы в общий VM-контекст Node.js, эмулируя то, как Apps Script делит один глобальный scope между всеми файлами проекта.

## Диагностика

- `logging.gs` — простое логирование в отдельный лист/консоль выполнения Apps Script (**Выполнение** в левом меню редактора).
- `testing.gs` — набор ручных диагностических функций, которые можно вызвать прямо из редактора Apps Script (выделите функцию → кнопка ▶ «Выполнить») для проверки состояния таблицы без прогона всего мастера заново.
