# TT Tournament Manager

*[Read this in English](README.en.md)*

Google Apps Script для проведения турниров по настольному теннису (и другим ракеточным видам спорта) прямо в Google Таблицах: регистрация участников через Google Форму, автоматическая жеребьёвка (группы + плей-офф), ведение матчей и результатов, возрастные/гендерные категории с автослиянием малых категорий, парные разряды, отчёты и рейтинг — без какого-либо внешнего сервера или базы данных. Вся логика турнира живёт в одной таблице и управляется через собственное меню, которое появляется в её интерфейсе.

Проект не является частью основного веб-приложения Pingo (`/opt/pingo`) — это отдельный, самостоятельный инструмент для организаторов турниров, который работает поверх экосистемы Google (Sheets, Forms, Drive, Apps Script).

## Возможности

- **Мастер создания турнира** (`wizard.gs`, `setup.gs`) — пошаговая настройка нового турнира: название, формат, количество кортов, категории.
- **Регистрация участников** (`forms.gs`, `participants.gs`) — приём заявок через Google Форму, импорт/экспорт списка участников, обработка одиночных и парных заявок.
- **Категории** (`categories.gs`) — разбивка участников на возрастные/гендерные категории (дети/подростки/взрослые × М/Ж) с автоматическим слиянием малых категорий и режимом «смешанный турнир».
- **Жеребьёвка** (`draw.gs`) — формирование групп и сетки плей-офф (single elimination), посев участников.
- **Матчи** (`matches.gs`) — ведение результатов, расчёт рейтинга, расписание по кортам.
- **Команды/пары** (`teams.gs`) — поддержка парных разрядов.
- **Оформление** (`theme.gs`) — единый визуальный стиль листов таблицы.
- **Google Drive** (`drive.gs`) — создание папки турнира и перенос в неё таблицы.
- **Отчёты** (`reports.gs`) — итоговые отчёты по турниру.
- **Меню** (`menu.gs`) — единая точка входа для организатора: все функции доступны из кастомного меню «🏓 TT Tournament Manager» в самой таблице.
- **Логирование и диагностика** (`logging.gs`, `testing.gs`) — вспомогательные инструменты для отладки на живой таблице.

## Структура репозитория

```
tournament/
├── categories.gs      # Возрастные/гендерные категории
├── config.gs           # Хранение и чтение настроек турнира
├── draw.gs              # Жеребьёвка: группы и плей-офф
├── drive.gs             # Работа с Google Drive
├── forms.gs             # Google Форма регистрации
├── logging.gs           # Логирование
├── matches.gs           # Матчи, результаты, рейтинг
├── menu.gs              # Кастомное меню Apps Script
├── participants.gs      # Участники: импорт/экспорт, статусы
├── reports.gs           # Итоговые отчёты
├── setup.gs             # Дирижёр создания турнира
├── teams.gs             # Команды/пары
├── testing.gs           # Ручная диагностика в таблице
├── theme.gs             # Оформление листов
├── wizard.gs             # Мастер настройки нового турнира
├── tests/                # Автотесты чистой логики (Node.js)
└── Pravila_nastolnogo_tennisa_*.pdf  # Официальные правила настольного тенниса (справочно)
```

## Технологии

- **Google Apps Script** (V8 runtime, классы ES2020). Все `.gs`-файлы делят один глобальный scope — это норма для Apps Script, а не архитектурная ошибка.
- Без внешних зависимостей и без сборки — код разворачивается как есть через редактор Apps Script или [`clasp`](https://github.com/google/clasp).
- Автотесты — только для «чистой» части бизнес-логики (например, `Categories.gs`), которая не обращается к `SpreadsheetApp`/`DocumentApp`. Запускаются встроенным `node:test` (Node 18+), без дополнительных npm-пакетов.

## Установка и запуск

Подробная инструкция — в [SETUP.md](SETUP.md).

Коротко:
1. Создайте новую Google Таблицу.
2. Откройте «Расширения → Apps Script».
3. Скопируйте все файлы `*.gs` из этого репозитория в проект Apps Script (либо разверните через `clasp push`, настроив `.clasp.json` — он не хранится в репозитории).
4. Сохраните и перезагрузите таблицу — появится меню «🏓 TT Tournament Manager».
5. Запустите мастер создания турнира из меню.
